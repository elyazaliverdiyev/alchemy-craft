## 🚀 Quickstart & Installation

1. Copy `main.js`, `manifest.json`, and `styles.css` into your `.obsidian/plugins/artcraft-reader/` folder.
2. Reload the app (`Ctrl+R` / `Cmd+R`) and enable **Alchemy Craft** in Settings.
